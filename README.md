## Deploy free using GitHub Pages
1. Download and extract this ZIP file.
2. Open https://github.com/new and create a **Public** repository named `balaji-portfolio`.
3. Upload the contents of the extracted folder into the repository root. Upload the files and `assets` folder, not just the ZIP.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to publish. The site URL will look like `https://Balaji-Muppuri.github.io/balaji-portfolio/` (use the exact URL shown by GitHub).
8. Test the site on desktop and mobile. Check the résumé download and social links.

## Editing
- Edit text and links in `index.html`.
- Change colors and layout in `style.css` (the main palette is at the top in `:root`).
- Change menu or footer behavior in `script.js`.
- Commit your changes to GitHub; Pages republishes the site automatically.
